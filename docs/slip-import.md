# 전표 불러오기 지원 범위

`SlipImportDialog`의 원천 목록은 각 입력 화면이 실제 API 어댑터를 등록한 경우에만 노출됩니다.

- 구매입력: 발주요청, 확정 구매. 관련 입고 수량이 있는 경우 품목코드별 잔량을 계산합니다.
- 발주요청입력: 발주요청 API.
- 판매계획입력: 판매계획 API.
- 견적 등 `SlipSourceType`에만 선언된 원천은 어댑터/API가 연결될 때까지 노출하지 않습니다.

불러오기는 원천 문서를 수정하거나 자동 저장하지 않습니다. 선택한 품목만 새 입력 초안에 복사하며, 최종 저장은 대상 입력 화면의 저장 동작에서만 수행됩니다. 발주요청과 입고 전표 사이에 문서별 연결 데이터가 없는 환경에서는 발주요청 잔량을 추정하지 않고 원수량을 표시합니다.
