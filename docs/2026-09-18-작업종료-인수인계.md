- Production DB와 Neon `main`은 runtime 테스트에 사용하지 않음
- Production 배포·DB schema 변경은 별도 승인 없이 수행하지 않음
- 비밀번호, API key, token, connection string을 채팅·문서·로그에 기록하지 않음
